# Personal Finance Tracker API 

A backend API for tracking personal income and expenditure. Built as an MVP for a fintech-style internal tool. Users can register, log in, record transactions, categorise spending, set monthly budgets, and view spending summaries. 

## Features: 
- User registration & JWT authentication
- Full CRUD for transactions, scoped so users can only ever see their own data 
- Category support (seeded defaults, plus custom categories)
- Monthly spending summaries with date/category filtering
- Budgeting with actual spend comparisons 
- Input validation and structured error responses
- Automated test suite (Pytest)

## Tech Stack:

- Python 3.10+ / FastAPI
- SQLAlchemy ORM + SQLite (dev)
- JWT auth (PyJWT) with bcrypt password hashing 
- Pytest for automated testing 

## Prerequisites:

- Python 3.10 or later
- Git

## Setup:

1. **Clone the repoository**
```bash
   git clone https://github.com/kpb510/finance-tracker-api.git
   cd finance-tracker-api
```

2. **Create and activate a virtual environment**
```bash
   python3 -m venv .venv
   source .venv/bin/activate
```

3. **Install dependencies**
```bash
   pip install -r requirements.txt
```

4. **Set up environment variables**

   Copy the example file and fill in your own secret key:
```bash
   cp. .env.example .env
```
   Generate a secure key and paste it into a `.env` as `SECRET_KEY`:
```bash
   python3 -c "import secrets; print(secrets.token_hex(32))"
```

## Running the app

```bash
   uvicorn app.main:app --reload
```

The API will be available at `https://127.0.0.1:8000`.

Interactive API documentation (auto-generated by FastAPI) is available at:
- Swagger UI: `http://127.0.0.1:8000/docs`
- ReDoc: `http://127.0.0.1:8000/redoc`

On first run, the database file (`finance.db`) and a set of default categories (Food, Transport, Bills, Entertainment, Shopping, Health, Other) are created automatically.

## Running tests

```bash
   pytest -v
```

Tests run against separate SQLite database (`test.db`) and never touch your development data.

## API overview

All endpoints except registration and login require an `Authorization: Bearer <token>` header, obtained from `POST /auth/login`.

| Method | Endpoint                | Description                          |
|--------|--------------------------|---------------------------------------|
| POST   | `/users`                 | Register a new user                   |
| POST   | `/auth/login`             | Log in, returns a JWT                 |
| GET    | `/transactions`           | List your transactions (filterable)   |
| POST   | `/transactions`           | Create a transaction                  |
| GET    | `/transactions/{id}`      | Get a single transaction              |
| PUT    | `/transactions/{id}`      | Update a transaction                  |
| DELETE | `/transactions/{id}`      | Delete a transaction                  |
| GET    | `/categories`             | List all categories                   |
| POST   | `/categories`             | Create a custom category              |
| GET    | `/summary/monthly`        | Get income/expense totals for a month |
| GET    | `/budgets`                | List your budgets with actual spend   |
| POST   | `/budgets`                | Create a budget                       |

### Filtering transactions

`GET /transactions` accepts optional query parameters:
- `start_date` (YYYY-MM-DD)
- `end_date` (YYYY-MM-DD)
- `category_id`

Example: `GET /transactions?start_date=2026-09-01&category_id=2`
