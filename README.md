# Personal Finance Tracker API 

A backend API for tracking personal income and expenditure. Built as an MVP for a fintech-style internal tool. 

## Features (Planned): 
- User registration & JWT authentication
- CRUD for transactions
- Categories (food, transport, bills, etc.)
- Monthly spending summaries with date/category filtering
- Basic budgeting 
- Input validation and structured error responses

## Tech Stack
- Python + FastAPI
- SQLAlchemy + SQLite (dev) / PostgreSQL (prod-ready)
- Pytest
- Docker
